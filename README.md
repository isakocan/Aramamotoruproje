# BLM3120 Dönem Projesi – Türkçe Yorumlarda Yıldız Tahmini (Multi-Agent)

Türkçe e-ticaret yorumlarından (MüşteriYorumları) 1–5 yıldız tahmini yapan, smolagents ile yazılmış çok ajanlı veri bilimi uygulaması.

- **Grup:** İsa Koçan (22011056), Bilal Efe Uysal (22011031)
- **Algoritmalar:** Decision Tree / k-NN / Random Forest
- **LLM:** NVIDIA Build – Nemotron 3.5 Lightning
- **GUI:** Streamlit
